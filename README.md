# Sammy Agent Skill Pack

A snapshot of all skills available in the Codex session on November 25, 2026.

Contains **127 skill definitions** across local skills, the Vara skill pack, system skills, and plugin-provided skills. Supporting scripts, references, templates, assets, and existing license files are included.

## Using the pack

Browse the catalog below and open a skill's `SKILL.md` for its instructions and dependencies. Copy the desired skill directory into the skill directory supported by your agent. Preserve its supporting files and relative directory structure. Plugin skills may require their original plugin tools, accounts, or services; copying instructions does not install those integrations.

`manifest.json` lists the source packages and credential sanitization. A bundled AI33 API credential was replaced with `YOUR_AI33_API_KEY`; configure your own credential before using that script. Original installed skills were not modified.

## Attribution and licenses

This is a collection of skills from multiple sources, not a claim of original authorship. Existing attribution and license files are preserved. Each component remains subject to its original license or terms; this repository does not grant additional rights.
